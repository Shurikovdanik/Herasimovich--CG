# Лабораторная работа 2 — вариант 4

Приложение демонстрирует обработку полутоновых изображений для варианта 4:
повышение контраста (линейное min-max-преобразование и эквализация
гистограммы), а также сегментацию по точкам, линиям и перепадам яркости.
Графический интерфейс показывает результаты рядом с исходным изображением,
чтобы методы можно было сравнить на одном и том же входе.

## Реализованные методы

- **Линейное контрастирование min-max.** Минимальная и максимальная яркости
  входа отображаются в диапазон 0–255 линейной функцией. Если изображение
  постоянной яркости, результат заполняется нулями.
- **Эквализация гистограммы.** OpenCV преобразует кумулятивное распределение
  яркости (CDF), чтобы распределить значения по доступному диапазону.
  Интерфейс выводит гистограммы исходного, min-max-преобразованного и
  эквализированного изображений, а также нормированную CDF исходного.
- **Обнаружение точек.** Используется модуль отклика лапласиана; порог
  выбирается по 99,5-му процентилю отклика и ограничивается снизу значением 30.
- **Обнаружение линий.** Вероятностное преобразование Хафа ищет отрезки на
  границах Кэнни. Перед поиском применяется гауссово сглаживание.
- **Обнаружение перепадов яркости.** Показаны бинаризованная величина градиента
  Собеля и границы детектора Кэнни.

## Проверочные изображения

Выпадающий список содержит исходное, малоконтрастное, зашумленное и размытое
изображения. Три тестовых варианта строятся при запуске из `data/imageBW.png`;
шум воспроизводим и использует фиксированное начальное значение генератора.
Поэтому методы можно сравнить на одинаковых данных, а результаты повторного
запуска не меняются. Кнопка **Open image…** позволяет загрузить собственное
изображение; оно автоматически читается в градациях серого.

## Запуск

Нужен Python с Tkinter. Установите зависимости из корня проекта:

```powershell
python -m pip install -r requirements.txt
```

Запустите приложение:

```powershell
python .\scripts\main.py
```

Виртуальное окружение проекта можно использовать вместо системного Python:

```powershell
.\.venv\Scripts\python.exe .\scripts\main.py
```

## Проверки

Запустите модульные проверки из корня проекта:

```powershell
python -m unittest discover -s tests
```
