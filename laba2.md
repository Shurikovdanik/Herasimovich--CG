# Лабораторная работа 2 — вариант 4

Приложение обрабатывает полутоновые изображения и сравнивает повышение
контраста с обнаружением точек, линий и перепадов яркости.

## Методы

- Линейное контрастирование методом min-max.
- Эквализация гистограммы; исходная, линейно преобразованная и
  эквализированная гистограммы показаны для сравнения вместе с CDF исходного
  изображения.
- Обнаружение точек по отклику лапласиана.
- Обнаружение линий преобразованием Хафа по границам Кэнни.
- Обнаружение перепадов яркости градиентом Собеля и детектором Кэнни.

## Запуск

Из корневой папки проекта запустите:

```powershell
.\.venv\Scripts\python.exe .\scripts\main.py
```

Приложение открывает `data/image.png`. В списке доступны исходное,
малоконтрастное, зашумленное и размытое тестовые изображения; эти варианты
создаются воспроизводимо из исходного изображения. Кнопка «Open image…»
позволяет загрузить другое изображение.
